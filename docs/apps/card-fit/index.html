CardFit Support

CardFit cleans, validates and repackages contact files selected from the Files app.

Supported input

Select one or more .vcf files containing vCard 2.1, 3.0 or 4.0 contacts. CardFit does not modify the source files or require access to your Contacts library.

Export package

The exported ZIP includes a cleaned combined vCard 3.0 file, individual VCF cards, a contacts CSV, an issue report and a summary.

Purchase help

The first export is free per device. CardFit Lifetime is a non-consumable purchase handled by Apple. Use “Restore purchase” in the app when using the same Apple Account on another device.
