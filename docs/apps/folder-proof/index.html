FolderProof Support

FolderProof creates a deterministic CSV and JSON inventory for a folder selected in Apple’s Files picker.

Quick answers

  • Your original files are never edited, renamed, moved, copied or deleted.
  • Each regular file receives a streaming SHA-256 integrity hash.
  • A manifest is marked incomplete if any selected file cannot be certified.
  • Symbolic links are reported and never followed outside the selected folder.
  • CSV and JSON are exported together through Apple’s share sheet.
  • Lifetime access can be recovered with Restore Purchases.

Files providers

FolderProof can only read the folder you explicitly choose. iCloud Drive and third-party providers decide whether cloud files are downloaded and currently accessible. Make unavailable files local in Files and try again if the manifest reports an issue.

Contact
