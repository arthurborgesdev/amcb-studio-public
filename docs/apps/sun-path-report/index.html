SunPath Report Support

SunPath Report creates a dated, labeled solar-position record from a site, date, time and IANA time zone.

Quick help

  1. Tap the map or enter latitude and longitude.
  2. Add a site label, choose the local date and time, and confirm the time-zone identifier.
  3. Generate the report, then export both PNG and PDF from the result screen.

Location is optional

You can deny location access and use manual coordinates. If you request the current location, iOS supplies coordinates and a reported horizontal accuracy. SunPath Report does not require Contacts, Photos, camera or account access.

What the report means

The app calculates the geometric solar position from the supplied coordinates and time. It does not simulate buildings, terrain, trees, weather, physical shadows or solar-energy yield. Verify critical field decisions independently.
