XML Lens Support

XML Lens turns local XML files into a navigable tree, precise validation result, searchable paths, and a private export package.

Before contacting support

XML Lens accepts regular .xml files up to 25 MB. The original file is never modified. A normalized copy is intentionally omitted when mixed content, comments, processing instructions, or a DOCTYPE could make reformatting unsafe.
