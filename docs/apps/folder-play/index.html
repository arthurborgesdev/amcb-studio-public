FolderPlay Support

FolderPlay turns the supported audio files inside a folder into one naturally ordered playback queue. It reads the folder and its subfolders without moving or changing the original files.

Getting started

  1. Tap Choose audio folder.
  2. Select a folder in the Files picker.
  3. Tap any track or use the playback controls to listen in order.

FolderPlay supports common audio formats including AAC, AIFF, ALAC, CAF, FLAC, M4A, M4B, MP3 and WAV. If folder access expires, choose the same folder again to renew it.
